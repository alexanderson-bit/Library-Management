# Library Management System
### 📖 Description

This project is a simple Library Management System implemented using object-oriented programming. It is designed to manage books, users, and library operations such as borrowing and returning books.

*The system is built using three main classes:*
+ User
+ Book
+ Library

### 🚀 Features

+ Add and manage users
+ Add and store books
+ Borrow books from the library
+ Return borrowed books
+ Track available and borrowed books

### 🧱 Project Structure

*The project consists of three main classes:*
+ **User**
    + Stores user information
    + Represents a library member
+ **Book**
    + Contains book details (title, author, etc.)
    + Tracks availability status
+ **Library**
    + Manages users and books
    + Handles borrowing and returning operations
